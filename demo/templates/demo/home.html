What this is

A minimal, real Django site used to demonstrate and screenshot django-tourguide. The package has no user interface of its own, so this stands in for a host project.

Something to point at

Tour steps anchor to elements by CSS selector. Elements here carry data-tour attributes so steps target a stable hook rather than a style class that might be restyled later.

The Settings page is the second page a multi-page tour can navigate to.
