{% load static tourguide %} {% comment %} `?bs=3`, `?bs=4` or `?bs=5` loads that Bootstrap and the matching tour theme, which is how the themes are checked against the real frameworks rather than against a guess at them. `?dark` adds Bootstrap 5's dark mode, which the theme follows without a second stylesheet. The choice is read from the session rather than the query string, because a tour that crosses to the other page navigates to a plain path and would otherwise lose its theme mid-tour. The stylesheets are not in the repository.
